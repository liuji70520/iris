问题

自身免疫病里，我们最想知道的不是某个 TCR 理论上能识别什么。

而是患者体内哪些克隆真的在致病、它们处于什么状态、被什么驱动、治疗后怎么变。 这要求同时看见克隆的"身份"（受体序列）与"状态"（转录表型）——单模态模型各只能看到一半。

联合模型停留在前预训练时代

CoNGA、Tessa、mvTCR、MIST、TSTScope 全部从零训练或小修小补——没有人把 scGPT 类转录组基础模型与 SCEPTR 类组库模型同时作为初始化做联合微调。

BCR / 体液免疫完全空白

现有联合模型 100% 只做 TCR。而自身免疫的核心标志物在 B 细胞——自身抗体、SHM 突变负荷、类别转换、生发中心反应——零件都在，没人组装。

自身免疫场景空白

mvTCR / MIST / TSTScope 全部是感染与肿瘤——强抗原、单克隆扩增。自身免疫是慢性、低亲和力、多克隆场景，联合模型的行为此前无人验证。

CIMA-RD 的每个细胞天然同时携带转录组与配对 TCR/BCR——联合建模是唯一能吃满这一数据结构优势的路线。 克隆给细胞一个身份，转录组给克隆一个状态。

能力

四个层层递进的任务

T3

致病克隆定位

以"克隆扩增 × 病灶富集 × 跨患者共享"三判据定位候选自身反应克隆，并读出每个克隆所处的活化 / 耗竭 / 细胞毒性功能状态——自身免疫版 PrediTCR，输出可直接衔接抗原验证实验。

T4

疾病活动度评分

克隆扩增程度与转录状态联合量化为患者级评分，与 SLEDAI / DAS28 等临床指标显著相关——通向疾病分型与疗效监测的分子标志物。

追踪

跨组织克隆追踪

外周血 ↔ 病灶组织的克隆时空足迹：以组织轴替代时间轴，描绘克隆的迁移与归巢，并与 Stereo-seq 空间转录组衔接"时空"叙事。

T6

干预响应模拟

在横断面数据上学习"疾病活动 / 用药"在联合潜空间中的扰动向量（scGen / CPA 范式），预测治疗把克隆推向什么状态——无需纵向配对样本。

快速开始

三行代码，嵌入你的细胞

install 
# 安装（Python ≥ 3.10）
$ pip install iris-air

# 数据要求：AnnData，obs 含克隆型标注
# （scirpy / Dandelion 双轨质控输出）
quickstart.py 
import iris_air as iris

model = iris.load("iris-base")          # 双预训练联合模型
model.embed(adata)                         # → obsm["X_iris"]

scores = model.score_activity(adata)       # 患者级活动度
clones = model.locate_pathogenic(adata)    # 致病克隆定位
delta  = model.perturb(adata, target="remission")
